---
title: Generate and edit images with AI
description: Generate an image, edit an image layer, or fill a selected area through fal.
icon: ImagePlus
---

Sign in and open a project saved to SocialFlow.ai. Choose **AI images** in the editor header. For a local project, the panel offers **Save to SocialFlow.ai** first; your original local project remains in the browser.

Your instance must have [fal configured](/self-hosting/ai#image-generation-with-fal). You need permission to edit the Workspace.

## Choose an action

- **Generate image** creates an image from your description. Open the model and quality summary to choose quality, shape and background. GPT Image 2.5 Flare is the default; Sunburst is also available.
- **AI edit image** edits the source image of one selected, unlocked image layer. You can also open it from the layer's properties. Describe the change, such as replacing the background. The layer keeps its position, crop, opacity and effects when you apply the result.
- **Fill selection** uses the current page as context. Select an area with the rectangle, lasso or magic selection tool, then describe what belongs there. The result is clipped to that selection and added as a separate layer. Pixels outside the selection stay unchanged. Use a canvas of 16 megapixels or less.

The prompt and source image are sent to fal. Generation continues when you close the panel or leave the editor.

## Review and apply

The panel shows the saved request's progress and result. For edits and fills, **Show original** lets you compare it with the source. Apply the result only when you are satisfied. Every application can be undone.

An edit applies to the layer selected when you submitted it, even if you select another layer while waiting. If that layer changes, SocialFlow.ai prevents replacement. You can restore the original layer or choose **Add as new layer**. Fill also requires the original page to remain unchanged.

Reopen **AI images** to see your recent requests for this project. Generated images are also stored in the Workspace's Media library.

## Check cost and recover a request

SocialFlow.ai records each paid request in your existing per-user AI usage history. Image generation has no separate credit balance or spending limit. Ordinary Media storage and upload limits still apply.

Costs are matched to fal's request ID. **Cost pending** means fal has not yet reported a charge; it does not mean the request was free. SocialFlow.ai continues checking for up to 72 hours.

If the browser loses the response, choose **Recover this request**. It reuses the same request identity. If fal accepted a request but its receipt was lost, SocialFlow.ai shows **Submission uncertain** and does not automatically submit it again. Ask your instance administrator to check fal before starting another generation.

A download or Media save failure is retried without generating another image. SocialFlow.ai keeps the provider receipt and any reported cost if it cannot recover the result within 24 hours.
